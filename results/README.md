# Ergebnisse

Hier werden nur kleine, aggregierte und nicht sensible Ergebnisdateien
versioniert, beispielsweise Tabellen mit Metriken oder kurze Markdown-Berichte.

Nicht einchecken:

- Vorhersagen mit vollständigen Artikeltexten;
- Modellgewichte und Checkpoints;
- umfangreiche Trainingslogs;
- Dateien aus dem offiziellen Development- oder Testset.

Jeder Ergebnisbericht nennt mindestens Commit, Datenversion, Sprache, Split,
Seed, Modell, Threshold, Micro-F1 und Macro-F1.
