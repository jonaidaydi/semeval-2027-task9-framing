# Team-Workflow

Änderungen kommen über einen Pull Request nach `main`.
Mindestens ein anderes Teammitglied prüft den Pull Request.
`main` soll ausführbar bleiben.

Jeder Modellvergleich dokumentiert Datenversion, Sprache, Split, Seed,
Hyperparameter, Schwelle, Micro-F1, Macro-F1 und ausgeführten Befehl.
Absätze eines Artikels und identische Texte dürfen nicht über
Trainings- und Validierungsgruppen verteilt werden.

Daten, Checkpoints, vollständige Vorhersagen und Zugangsdaten bleiben lokal.
