# Codabench-Downloads

Die Downloads **full-data_2026_11_16** und **starting-kit-v2** hier ablegen.
ZIP-Dateien nicht umbenennen oder manuell entpacken. Bereits entpackte Ordner
werden ebenfalls erkannt, auch mit zusaetzlichen Unterordnern.

Der Full-Data-Download kann `data-fourth-batch-russian-2026_11_1.zip` heissen.
Er enthaelt auch die englischen Daten. Das Projekt verwendet ausschliesslich Englisch.

Danach im Projektordner `projekt.py einrichten` mit Python 3.13 starten.
Die vollstaendigen Windows- und macOS-Befehle stehen im [README](../README.md).

Downloads und automatisch eingerichtete Daten bleiben lokal und werden von Git ignoriert.
